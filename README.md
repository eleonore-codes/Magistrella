🏛️ Magistrella

Magistra (Lehrerin) + -ella (Verniedlichung) = „Die kleine Lehrerin — immer in der Tasche"

Ein personalisierter Latein-Grammatik-Trainer für Gymnasiastinnen, aufgebaut Lektion für Lektion parallel zum Lehrwerk.

✨ Features
📖 Alle Vokabeln direkt aus prima. — mit korrekten Längezeichen (ā ē ī ō ū)
🎯 Nur echte Mustersätze in den Grammatikübungen
🔀 Vollständig randomisierte Fragen — jede Session anders
📱 Mobile-first, offline-fähig, keine externen Abhängigkeiten
🛡️ LRS-freundlich — keine falschen Schreibweisen als Distraktoren, keine Freitexteingabe
🎉 Konfetti, lateinische Affirmationen und ein dunkles Pergament/Mosaik-Theme
📚 Struktur
Magistrella/
├── index.html        ← Hub (Klassen- und Lektionsübersicht)
└── l7/               ← Klasse 7
    ├── l01.html      Kap. 1
    ├── l02.html      Kap. 2
    ├── l03.html      Kap. 3
    └── l04.html      etc.
🛠️ Technologie
Reines HTML/CSS/JS — eine selbst-enthaltene Datei pro Lektion
Keine Frameworks, keine Build-Tools, kein externes CDN
KI-gestützte Entwicklung (Vibe Coding mit Claude)
🎯 Design-Prinzipien
Vokabelpool wird bei jedem Start neu randomisiert
Grammatikfragen nur mit belegten prima.-Mustersätzen
Distraktoren sind immer korrekte lateinische Formen (falsche Person/falscher Kasus) — nie Schreibfehler
Regelkarten nur bei Grammatikfragen, nicht bei Vokabelfragen
Puzzle-Sätze: Subjekt immer zuerst, Reihenfolge der Verben flexibel
